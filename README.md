# Netcord: public pages

The privacy policy and support pages for Netcord, a tennis tracker and
coach for iPhone, Apple Watch and Garmin, served by GitHub Pages at
https://liniker-seixas.github.io/netcord/.

This repository holds only these pages; the app lives elsewhere. App Store
Connect links to:

- Privacy policy: https://liniker-seixas.github.io/netcord/privacy/
- Support: https://liniker-seixas.github.io/netcord/support/

`privacy.md` must say exactly what the app's own privacy policy says. When
the policy changes, update both, then push; Pages rebuilds in about a
minute.
